### Critical Cross-Phase Wiring: Phase 01 → Phase 02

The Phase 01 frame-0 fix and Phase 02 loading gate are correctly integrated:

```
loadCase()
  → dataReady=false, videoReady=false  [Phase 02: gate opens]
  → fetch → data.value = parsed
  → dataReady=true
  → currentFrame=0, zoomLevel=1, panOffset=0, playbackRate=1  [Phase 01: state reset]
  → nextTick: seekToFrame(0) → currentFrame=0, scheduleDraws(1)
     (videoRef null here — no-op on currentTime, but frame state set for BUG-02)

watch(currentPartVideoUrl)
  → videoSrc = newUrl
  → loadedmetadata listener: seekAndPlay
      → videoRef.currentTime = 0  [actual seek to frame 0]
      → videoReady=true           [Phase 02: gate closes, loading screen hides]
```

The `seekToFrame(0)` nextTick call sets `currentFrame=0` before the video loads, which is what BUG-02 depends on for the canvas overlay to draw frame-0 detections. The real `currentTime=0` seek happens in `seekAndPlay`. Functionally correct for normal-path raw-mode loads.
