<objective>
Make the transitions matrix always render as a square and reflow correctly when the right panel is resized.

Purpose: The current hardcoded `200` constant in the `transitionMatrix` computed ignores panel width changes. A ResizeObserver on the always-present `.right-panel` div drives a reactive `matrixContainerWidth` ref, which the computed uses to derive a dynamic `squareSize` (capped at 320px, with a 14px cell floor). The wrapper div inside the transitions section receives explicit `width` and `height` style bindings to enforce the square shape.

Output: Updated `YOLOVisualizer.vue` with ResizeObserver lifecycle + dynamic square sizing; new TRANS-01/TRANS-02 tests in the spec file.
</objective>
