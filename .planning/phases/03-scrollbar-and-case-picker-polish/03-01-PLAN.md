<task type="auto">
  <name>Task 1 (Wave 1): Add global scrollbar CSS to index.html</name>
  <files>web/frontend/index.html</files>
  <action>
    Edit `web/frontend/index.html`. Inside the existing `<style>` block (lines 7-11), append the following CSS after `body { overflow: hidden; }`:

    ```css
    /* Custom scrollbars — Chromium/WebKit */
    ::-webkit-scrollbar { width: 6px; height: 6px; }
    ::-webkit-scrollbar-track { background: transparent; }
    ::-webkit-scrollbar-thumb { background: #2a2a3a; border-radius: 3px; }
    ::-webkit-scrollbar-thumb:hover { background: #3c3c4e; }
    /* Custom scrollbars — Firefox (standard spec, Baseline 2022) */
    * { scrollbar-width: thin; scrollbar-color: #2a2a3a transparent; }
    ```

    CRITICAL: Do NOT place these rules inside a Vue component `<style scoped>` block — scoped styles inject a `[data-v-xxx]` attribute that pseudo-elements cannot carry, causing the rules to be silently dropped. The `index.html` inline style block is the only correct global CSS location in this project (confirmed: main.js has no CSS imports).

    The `scrollbar-color` value requires exactly two tokens: thumb color then track color. `scrollbar-color: #2a2a3a transparent` is correct. A single-token value is invalid in Firefox.

    Do not remove `body { overflow: hidden; }` — it is load-bearing for YOLOVisualizer's fixed viewport layout.

<task type="auto" tdd="true">
  <name>Task 2 (Wave 1): Fix CasePicker overflow layout</name>
  <files>web/frontend/src/components/CasePicker.vue</files>
  <behavior>
    - Test 2 from Task 0 (CasePicker.spec.js): `.upload-root` has `overflow-y: auto` — MUST turn GREEN after this task
  </behavior>
  <action>
    Edit the `<style scoped>` block in `web/frontend/src/components/CasePicker.vue`.

    Change `.upload-root` from:
    ```css
    .upload-root {
      min-height: 100vh; background: #06060a;
      display: flex; align-items: center; justify-content: center;
      font-family: 'JetBrains Mono', 'SF Mono', 'Fira Code', monospace;
      color: #e0e0e6;
    }
    ```
    To:
    ```css
    .upload-root {
      min-height: 100vh; background: #06060a;
      display: flex; align-items: flex-start; justify-content: center;
      overflow-y: auto;
      font-family: 'JetBrains Mono', 'SF Mono', 'Fira Code', monospace;
      color: #e0e0e6;
    }
    ```

    Change `.upload-center` from:
    ```css
    .upload-center { text-align: center; max-width: 860px; width: 100%; padding: 40px; }
    ```
    To:
    ```css
    .upload-center { text-align: center; max-width: 860px; width: 100%; padding: 40px; margin: 0 auto; }
    ```

    Rationale: `align-items: center` on a flex container with `min-height: 100vh` splits overflow equally above and below center — the top half is unreachable because `body { overflow: hidden }` suppresses body scroll. `align-items: flex-start` + `overflow-y: auto` makes the route container itself scroll. `margin: 0 auto` on `.upload-center` preserves horizontal centering. Do NOT remove `body { overflow: hidden }` — fix only at the component level.
  </action>
